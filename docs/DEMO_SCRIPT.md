# 自行体验说明

从首页 `/` 进入即可，不需要了解医药业务。你扮演一位准备拜访医生的代表；医生与材料都是演示数据。

- 查询：“最近互动记录和待办是什么？”
- 准备：“推荐长期安全资料。”；再试“推荐青少年生长发育资料。”
- 点击检索材料上的“打开此材料进行演示”，再点击底部提交结束这次模拟展示。
- 反馈：“医生不认可长期安全性，仍然担心风险。”
- 补充：“下周五上午复访，希望补充青少年资料。”
- 选择采纳或忽略待办；提交拜访时可编辑完整记录，确认保存。
- 再问：“上次拜访聊了什么，有哪些待办？”查看写入后的变化。

也可以自由改写问题，或使用“试填一段模拟拜访反馈”。没有匹配材料时应明确显示无结果。
“查看执行过程与依据”可了解本次工具轨迹以及规则／模型模式。
当前没有连接企业微信发送渠道，原有分享／远程操作为演示占位，不能代表实际发送。
